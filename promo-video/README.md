# LifeDock promo

A 30-second, 1080×1920 vertical social promo built with Remotion, including Amy's real voice recording cleaned with ElevenLabs Voice Isolator.

Render from the repository root:

```powershell
npx remotion render promo-video/index.ts LifeDockPromo output/lifedock-promo.mp4
```

The generated people are fictional. The video is designed to work silently with on-screen copy, making it suitable for autoplay social feeds.
